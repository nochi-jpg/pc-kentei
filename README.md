# 小学校パソコンスキルマスター

小学生（1〜6年）向けの、パソコン操作（トラックパッドとキーボード）の練習アプリです。
れんしゅうで操作を身につけ、試験に合格すると級の認定証がもらえます。

作った人：K.nom

## つかいかた

- `index.html` を Edge でひらくだけで動きます。
- 画像・音もすべてこのファイル1つに入っているので、学校へはこのファイルだけを持っていけば使えます（インターネットは不要）。
- 記録はその端末の Edge の中（localStorage）にだけ保存されます。

## 級とステージ

| 級 | 学年のめやす | ステージ |
|---|---|---|
| 3級 | 1・2年 | ログイン・ログアウト、クリック、ダブルクリック、右クリック、ドラッグ＆ドロップ、スクロール、ズーム、スタンプをおくる、キーワードで検索、ファイルを開く |
| 2級 | 3・4年 | 文字入力、文字をえらぶ、コピー＆はりつけ、切り取り＆はりつけ、元に戻す、フォルダーにせいり、名前を付けて保存、2つのことばで検索、画像を入れて大きさを変える |
| 1級 | 5・6年 | タイピング、漢字に変換、ショートカットキー、検索と置換、コメントを書く、ファイルを添付、共有の設定、変更履歴 |
| マスター | 1級合格後 | 3級〜1級の試験問題81問 |

## ファイル

- `index.html`：配布用（これだけで動く）
- `src/`：画面とステージのプログラム（style.css、core.js、ui.js、play.js、stages3/2/1.js、tips.js、boot.js）
- `assets/pasota/`：ぱそたの元画像、`assets/build/`：軽くした画像（webp）、`assets/se/`：効果音（過去作から）
- `build.py`：`src/` と `assets/` から `index.html` を作り直すスクリプト（`python3 build.py`）
- `test/`：1366×768 で全画面・全ステージをチェックする自動テスト（Playwright）
- `SPEC.md`：仕様書メモ

## 効果音

過去の作品のリポジトリから使っています：kimochi-search（cursor・decide・correct・wrong・finish・fav）、oekaki-relay（drum・clap）、manabi-life-assets（cheer・chime）。不合格の音はアプリ内で合成しています。
